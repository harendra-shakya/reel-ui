Agents

Read SKILL.md in the repo root. Recipe: pick template → swap tracks[].src → rewrite captions → node src/cli.js render. Constraints: drawtext is line-level (no per-word karaoke), max 2 wrapped lines, 1080×1920 default, font via REEL_FONT or fc-match auto-detect.
